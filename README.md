## GitHub `main` root structure

Everything belongs directly in the repository root except CSS and JavaScript:

```text
main/
├── index.html
├── history.html
├── estates.html
├── manjhwe-estate.html
├── harinandan-prasad-singh.html
├── govind-prasad-singh.html
├── chakradhar-prasad-singh.html
├── kamla-prasad-singh.html
├── family-tree.html
├── notable-people.html
├── bhoodan.html
├── enquiry.html
├── contact.html
├── img.jpg
├── css/
│   └── style.css
└── js/
    ├── script.js
    ├── family-data.js
    └── enquiry.js
```

**Important:** `img.jpg` is directly beside `index.html`. Replace the included placeholder `img.jpg` with your actual Kursinama/family image, keeping exactly the filename `img.jpg`.

Enable GitHub Pages:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
