# Sahevan Family Website

Files:
- index.html — all routed website pages/content
- style.css — complete responsive royal design
- script.js — routing, dark mode, estate menu, family tree and enquiry engine
- img.jpg — place your Kursinama image here

Open index.html in a browser. For hosting, upload all files to the same folder.

The enquiry system is local JavaScript and answers only from the structured facts included in script.js.
